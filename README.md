💰 AI Expense Tracker

🚀 Track Your Money. Manage Your Budget. Build Better Financial Habits.

AI Expense Tracker is a smart personal finance management web application designed to help users track their income, expenses, and budget in one place.

It provides an interactive dashboard where users can monitor their financial activities, manage transactions, analyze spending patterns, and make better financial decisions.

Track Smart. Spend Wise. Save More! 💸

---

✨ Key Features

- 💰 Income Tracking – Add and manage your income.
- 💸 Expense Management – Record and organize daily expenses.
- 📊 Interactive Dashboard – View total income, expenses, and balance.
- 📈 Expense Analytics – Analyze spending through visual charts.
- 🏷️ Category Management – Organize transactions by categories.
- 🎯 Budget Management – Set and monitor your spending limits.
- 🧠 AI-Powered Insights – Get intelligent financial insights if AI integration is enabled.
- 📅 Transaction History – View and manage previous transactions.
- 🔐 User Authentication – Secure login and registration.
- 📱 Responsive Design – Access the application on different screen sizes.

⚙️ Installation & Setup

1. Clone Repository

git clone https://github.com/ajit9129353710/AI-EXPENSE-TRACKER.git

2. Navigate to Project

cd AI-EXPENSE-TRACKER

3. Backend Setup

cd backend
npm install

Create a ".env" file inside the backend folder:

PORT=5000
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
GEMINI_API_KEY=your_gemini_api_key

Start Backend:

npm run dev

4. Frontend Setup

Open another terminal:

cd frontend
npm install

Create a ".env" file:

VITE_API_URL=http://localhost:5000

Start Frontend:

npm run dev

🧠 How It Works

1. User creates an account or logs in.
2. User adds income and expense transactions.
3. The application stores transaction data in MongoDB.
4. Dashboard calculates total income, expenses, and available balance.
5. Charts display spending patterns and category-wise expenses.
6. User monitors budgets and transaction history.
7. AI-powered insights can help users understand their spending habits, if enabled.
